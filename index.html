💌 Tạo trang cho khách

1. Kết nối GitHub (mỗi máy nhập 1 lần)

Đã kết nối · đổi token

2. Tên khách → đường link

Link:

3. Lời nhắn & chữ trên trang

4. Ảnh (ảnh 1 to nhất, tối đa 5)

Ảnh tự thu nhỏ còn 1600px để trang tải nhanh. Không chọn file = giữ ảnh cũ.

5. Video

Nên dưới 50MB (GitHub chặn trên 100MB).

5b. Nhạc (khách yêu cầu mới cần)

Để trống cả hai = dùng bài mặc định. Link YouTube/Spotify/Zing không phát được, cần link file mp3 trực tiếp hoặc tải file lên (dưới 95MB).

6. Mặt dây chuyền & thẻ ID (chọn ảnh nào)
